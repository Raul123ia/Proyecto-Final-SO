INTERFAZ VISUAL DE LA GUI WIN32
═══════════════════════════════════════════════════════════════════

COMPONENTES:
────────────

1. BARRA DE BOTONES (Superiores)
   ┌─────────────┬────────────┬───────────┐
   │ Crear       │ Tick       │ Salir     │
   └─────────────┴────────────┴───────────┘

   • Crear:  Añade un nuevo proceso a la cola LISTO
   • Tick:   Avanza la simulación (ejecuta un proceso LISTO)
   • Salir:  Cierra la aplicación

2. ÁREA DE VISUALIZACIÓN (Tabla de Procesos)

   Columnas:
   ├─ PID        : Identificador único del proceso
   ├─ Name       : Nombre del proceso
   ├─ State      : LISTO | EJECUTANDO | ESPERANDO | TERMINADO
   ├─ Priority   : Nivel de prioridad (1 = mayor)
   ├─ Burst      : Tiempo de CPU restante
   └─ Mem        : Memoria asignada en MB

3. FLUJO DE USO:

   Arranque:
   ├─ Se crean 2 procesos iniciales (init, worker)
   ├─ Se muestran en la tabla
   └─ Se espera acción del usuario

   Al Pulsar "Crear":
   ├─ Se añade un nuevo proceso
   ├─ Nombre: proc_win_N (N = contador)
   ├─ Ráfaga: 5 unidades
   ├─ Prioridad: 1
   ├─ Memoria: 64 MB
   ├─ Estado: LISTO
   └─ Se refresaca la tabla

   Al Pulsar "Tick":
   ├─ El simulador busca un proceso en LISTO
   ├─ Lo cambia a EJECUTANDO
   ├─ Decrementa su Burst en 1 unidad
   ├─ Si Burst llega a 0 → TERMINADO
   └─ Se refresaca la tabla

4. EJEMPLO DE EJECUCIÓN:

   PASO 0 - Inicial (después de arranque)

CARACTERÍSTICAS DEL SIMULADOR
═══════════════════════════════════════════════════════════════════

✓ Creación dinámica de procesos
✓ Estados de proceso (LISTO, EJECUTANDO, ESPERANDO, TERMINADO)
✓ Planificación simple (FCFS - primero en llegar, primero en ejecutar)
✓ Decrementación de ráfaga con cada paso
✓ Prioridades y memoria asignada
✓ Múltiples vistas (consola + GUI Win32 + GUI Qt)
✓ Thread-safe (mutex en Model)
✓ Arquitectura MVC limpia
