🚀 CÓMO USAR AHORA
═══════════════════════════════════════════════════════════════════════════════

Opción 1: Consola (Interactiva - Prueba AHORA)
─────────────────────────────────────────────
cd C:\Users\isaia\CLionProjects\untitled-SimuladorDeProcesos\simulador-gestor-procesos
.\build\simulador.exe

Comandos:
  c → crear proceso
  t → ejecutar tick
  l → listar procesos
  q → salir

Opción 2: GUI Win32 (Gráfica - Prueba AHORA)
───────────────────────────────────────────
.\build\simulador_win.exe

Característ icas:
  • 6 botones en la barra superior (ESPAÑOL)
  • Tabla de procesos con columnas: ID | Nombre | Estado | Prioridad | Memoria
  • Panel de detalles (selecciona un proceso para verlo)
  • Medidores de CPU, Memoria, Total Procesos
  • Barra de estado con contadores

Opción 3: GUI wxWidgets (Profesional - Instala wxWidgets primero)
──────────────────────────────────────────────────────────────
# Instalar wxWidgets
winget install wxWidgets
# o desde: https://www.wxwidgets.org/downloads/

# Recompilar
cmake -G "MinGW Makefiles" -S . -B build
cmake --build build --config Debug

# Ejecutar
.\build\simulador_wx.exe
